# Python PostgreSQL CRUD

A simple Python project demonstrating how to connect to a PostgreSQL database and perform basic CRUD (Create, Read, Update, Delete) operations using `psycopg2`.

## Technologies
- Python
- PostgreSQL
- pgAdmin 4
- psycopg2

## Features
- Connect Python to PostgreSQL
- Create database tables
- Insert single and multiple records
- Retrieve records using `fetchall()`
- Update employee information
- Delete employee records
- Handle database errors and transactions

## Database

The project uses an `employee` table containing:

- `id` — Employee ID
- `name` — Employee name
- `salary` — Employee salary
- `dept_id` — Department ID
